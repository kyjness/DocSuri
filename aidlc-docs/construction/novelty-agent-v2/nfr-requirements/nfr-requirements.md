# Novelty Agent v2 — NFR Requirements

**Unit**: Novelty Agent v2 (U12)
**Stage**: NFR Requirements (2026-07-18, 질문 게이트 Q1~Q6=A)
**환경 원칙**: 모든 요구는 헥사고날 포트 기준이다. 루프 코어·도메인은 실행 환경(큐·LLM·저장소 구현)을 모르며, 아래의 구현 선택은 1차 어댑터(로컬 컨테이너 체제)에 대한 것이다. 배포 재개 시 교체 경로는 `tech-stack-decisions.md`의 TD 항목에 병기한다.

## 1. 실행 표면 (Q1=A)

- **NFR-NV2-1**: 잡 실행은 API 프로세스 밖 — API는 잡 생성/조회/취소/대화만 담당하고, 루프는 **잡 큐 포트** 뒤의 별도 워커 프로세스가 실행한다(NFR-P5 구조 승계).
- **NFR-NV2-2**: 잡 실행은 `job_id` 단위 멱등이다 — 큐 재전달·중복 소비 시 실행 중 잡을 이중 기동하지 않는다(실행 잠금).
- **NFR-NV2-3**: 워커 크래시 복구 — 실행 중 상태로 남은 잡은 워커 재시작 시 stale로 감지해 `failed` 처리한다(v1 재개 미지원 — FD Q10=A). 검증·저장된 산출물과 트레이스는 유지된다.

## 2. 성능 프로파일

- **NFR-NV2-4**: 비-SLA 온디맨드 프로파일(NFR-P5 승계) — 검색 SLA(NFR-P1) 대상이 아니다.
- **NFR-NV2-5**: 잡 생성 API는 접수만 하고 즉시 응답한다(목표 P95 < 1s — 접수·검증·큐 적재).
- **NFR-NV2-6**: 활동 피드·상태 조회는 폴링 프로파일(권장 주기 2~5s)에 맞는 경량 쿼리여야 한다(커서 기반 증분 조회).
- **NFR-NV2-7**: 온디맨드 대화 턴(스티어링 응답·제안/실험계획 생성)은 잡 재실행이 아니라 단일 턴 처리이며, 장시간 생성은 동일 폴링 프로파일로 표시한다.

- **NFR-NV2-9**: 예산 소진 시 검증된 산출물만으로 `partial` 종료(FD BR-RA3) — 진행 중 도구 호출은 완료 후 종료.

## 4. 취소·저하

- **NFR-NV2-10**: 협조적 취소 — 취소 요청은 잡 레코드 플래그로 기록되고, 워커는 매 act(도구 실행) 전에 확인한다. 취소 지연 상한 = 진행 중 도구 호출 1건의 타임아웃.
- **NFR-NV2-11**: source별 저하 분리(NFR-R3 승계) — 도구 실패는 에이전트에 오류로 반환(대체 경로 판단 기회) 후 지속 실패 시 `degraded_sources` 기록. 재시도·서킷 브레이커 세부는 NFR Design.

## 5. 트레이스·피드 (FR-46, Q5·Q6=A)

- **NFR-NV2-12**: `ToolCallRecord`는 잡과 같은 저장소(postgres)의 잡 귀속 테이블에 기록하며, `(job_id, seq)` 순차 조회 인덱스를 가진다. 잡 삭제 시 cascade 삭제(BR-NV18 개정 정합). 보존 기한 = 잡 수명(별도 TTL 없음).
- **NFR-NV2-13**: 트레이스 기록 실패는 도구 호출을 실패시키지 않되(best-effort 아님 주의 —), **기록 불가 상태가 지속되면 루프를 중단**한다: 추적성(FR-46)은 계약이므로 트레이스 없는 실행을 계속하지 않는다.
- **NFR-NV2-14**: 활동 피드는 트레이스의 투영으로 폴링 제공(Q5=A). SSE 스트리밍은 후속 개선 항목(요구 아님).

## 6. 보안·프라이버시

- **NFR-NV2-15**: 외부 탐색 어댑터는 도구별 payload allowlist를 기계식으로 강제한다(FD BR-RA7) — 어댑터 단위 테스트로 차단성 검증.
- **NFR-NV2-16**: 트레이스·피드는 sanitized 요약만 저장·노출(SEC-9/15). 원고 원문·근거 전문·자격증명 저장 금지.
- **NFR-NV2-17**: Notion 토큰 암호화 저장·승인 게이트 승계(v1 NFR 기준선).

## 7. U6 예산 연동

- **NFR-NV2-18**: 잡 생성 시 U6 `get_budget_state()` 확인 — 저하 모드면 축소 배분 또는 기권. 루프 중 재판정하지 않는다(비용 단일 권위, 모듈 재판단 금지).
