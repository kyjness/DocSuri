# Novelty Agent v2 — NFR Design Patterns

**Unit**: Novelty Agent v2 (U12)
**Stage**: NFR Design (2026-07-18)
**원칙**: u2(의존성별 서킷 브레이커)·u7(결정론 게이트·저하 계층) 검증 패턴 재사용. 신규 프레임워크 도입 없음.

## 1. 의존성별 서킷 브레이커 (u2 패턴 재사용)

실패 도메인 단위로 분리: LLM / U2 검색 / evidence 엔진(U11) / 외부 탐색 어댑터(소스별) / 저장소. 한 의존성의 open이 다른 도구를 차단하지 않는다. open된 도구는 레지스트리에서 일시 비활성 — 에이전트의 다음 decide에 "사용 불가" 신호로 반영되어 대체 경로를 판단하게 한다(FD BLM §9와 정합).

## 2. 재시도·저하 계단

```
도구 호출 실패
 → 기계 재시도 1회 (outage 정신 — 그 이상 기계 재시도 없음)
 → 실패를 에이전트에 오류 결과로 반환 (대체 경로·재시도 판단은 에이전트 자율, 예산 내)
 → 소스 지속 실패(서킷 open) → degraded_sources 기록, 나머지로 진행 (NFR-R3)
 → 필수 산출물 완성 불가 → partial 종료 / 치명(권한·저장소) → failed
```

- LLM 자체 실패는 루프 진행 불가이므로: 1회 재시도 → 실패 시 검증된 산출물로 partial(가능하면) 또는 failed. LLM-불가를 다른 도구로 우회하지 않는다.
- 저장소 실패는 치명으로 취급(트레이스·산출물 계약 위반 방지 — NFR-NV2-13과 동일 정신).

## 3. 멱등 실행 잠금

큐 재전달·중복 소비 대비: 잡 실행 시작 시 `job_id` 잠금 획득(저장소 원자 연산). 잠금 보유자만 루프 실행. 워커 하트비트로 stale 감지 → 재시작 시 실행 중 고아 잡을 failed 처리(v1 재개 미지원). 트레이스 `seq`는 저장소 시퀀스로 발급해 중복 기동 시도 시 충돌이 드러나게 한다.

## 4. 예산 집행 지점

단일 지점 집행: 루프 코어의 act 직전 1곳에서만 검사·소비 기록(우회 경로 금지 — BR-RA2의 게이트 유일 관문과 동형). 토큰/비용은 도구·LLM 호출 결과의 사용량 보고를 합산하고, U6 `get_budget_state()`는 잡 생성 시 1회만 조회(NFR-NV2-18).

## 5. 관측 신호

- **1차**: `ToolCallRecord` — 구조화 관측의 SSOT(무엇을·왜·얼마나). 디버깅·재현은 트레이스 재생으로.
- **보조(best-effort, 실패 무해)**: 기존 텔레메트리 경로에 카운터 발행 — 잡 완료율, partial 비율(사유별: 예산/저하), 게이트 거부율, 평균 반복 수·도구 호출 수, 소스별 서킷 open 횟수. 게이트 거부율 급등 = 프롬프트/규칙 회귀 신호, 평균 반복 급등 = 예산 압박 신호.

## 6. 캐시

v2 신규 캐시 없음. 조사 결과는 잡으로 영속되고(재생성 개념 없음), 온디맨드 생성물도 잡에 병합 영속 — 동일 요청 재수신 시 기존 산출물 반환. 하부 캐시(U2 검색·U7 요약)는 각 유닛 소관 그대로.

## 7. 테스트 전략

- **포트 대역**: 모든 포트에 fake 구현(사내 관례) — 루프 코어는 LLM fake(각본형 결정 시퀀스)로 결정론 테스트.
- **PBT 배치**(QT-10 Partial): PBT-NV1~7 승계 + PBT-RA1(게이트 차단성 — 임의 결손 산출물 생성해 저장 시도), PBT-RA2(예산 단조·초과 시 미실행), PBT-RA3(트레이스 1:1·seq 무결) — Hypothesis.
- **어댑터 경계 테스트**: sanitize allowlist 차단성(NFR-NV2-15), 큐 멱등 잠금, stale 감지.
- **계약 테스트**: real_wiring 어댑터는 포트 계약 테스트를 로컬 대역과 공유(배포 재개 시 회귀 방지).
