# Evidence Agent v2 (U11) — NFR Requirements

**단계**: CONSTRUCTION → NFR Requirements (재설계 라운드) · **유닛**: U11 · **일자**: 2026-07-28
**근거**: FD 산출물 3종 · `requirements.md` NFR-P6·NFR-C1·NFR-R2·NFR-O1·SEC·QT-8·FR-45~47 · v1 frozen `u11-evidence-agent/nfr-requirements/`.
**고도**: NFR 목표(정책 형태) + **루프 상한 시작값**. 리전·IaC·CI 설정은 Infra/Build&Test 이월.
**v1 대비 동인 변화**: 한 턴의 LLM 호출이 **1회 → 반복**이 되고, **온디맨드 승격**이라는 새 비용·지연원이 생겼다. 두 가지가 이 문서의 대부분을 결정한다.

## 1. NFR 동인

| 동인 | 내용 |
|---|---|
| **NFR-P6** | 스트리밍 TTFB + 비동기 잡. 루프는 총 소요가 v1보다 길어질 수 있어 **진행 표시가 체감 지연을 흡수**해야 한다 |
| **NFR-C1** | 턴당 LLM 호출이 반복 + 승격 임베딩 비용 → **3중 한도(FR-45)가 안전 요건** |
| **NFR-R2** | 의존성 증가: 검색·DocModel 스토어·LLM·**외부 논문 소스**·**인제스천 빌드 경로** |
| **NFR-O1** | 결정 트레이스가 관측의 1차 산출물(FR-46) |
| **QT-8** | 날조 금지·기권 안전성·소유권 격리 + v2 신설 3속성(PBT-EV-6~8) |

## 2. 성능 (NFR-P6)

| 항목 | 요구(형태) |
|---|---|
| TTFB | 첫 활동 피드 항목이 **빠르게** 도달한다 — 루프 1회차 도구 실행 전 "접수/조사 시작"이 나간다 |
| 동기 경로 | 승격 없음·첨부 없음의 단순 질의는 동기 SSE로 완료 |
| 비동기 잡 | 승격 다수·첨부 포함은 잡 오프로드 + 폴링. **진행 중 경로 전환은 하지 않는다** |
| 승격 지연 | 본문 취득 + DocModel은 **동기**(초 단위 목표, ar5iv HTML 경로 기준). PDF+GROBID 폴백은 더 걸리며 실패 시 초록 범위로 즉시 수렴 |
| 색인 지연 | **응답 경로 밖**(백그라운드) — 지연 목표를 두지 않는다 |
| 세션·트레이스 조회 | 인덱싱된 (ownerId, sessionId) 기준 DB 조회 수준 |
| 검증 수치 | TTFB·턴 완료 분포·승격 소요 실측은 Build&Test |

- **진행 표시가 성능 요건의 일부다**: 루프는 언제 끝날지 예측이 어려우므로, 활동 피드가 끊기지 않는 것이 총 소요보다 사용자 체감에 크다.
- 스트리밍 중 **최종 claims는 검증 완료 전까지 노출하지 않는다**(INV-EV-3와 TTFB의 균형 — v1 승계).

## 3. 루프 상한 시작값 (FR-45 — BR-EV-13 수치화)

| 한도 | 시작값 | 근거 |
|---|---|---|
| 루프 반복 | **12** | 검색→읽기→재검색 사이클 3~4회를 감당하는 최소선 |
| `corpus_search` | **5** | 질의 재설계 여지를 주되 반복 질의로 캡을 태우지 않는 선 |
| `external_search` | **3** | 외부 호출은 지연·프라이버시 표면이 크다 |
| `fetch_paper` | **3** | 승격 1편당 취득·파싱·임베딩 비용. 한 턴에 4편 이상은 동기 지연이 체감된다 |
| `read_paper` | **8** | 확보 논문 본문 열람 |
| `view_figure` | **6** | 목록 조회도 1회 소비(novelty와 동일 계약) — 논문 하나 훑는 데 최소 2회 |
| `extract_evidence` | **8** | 게이트 탈락 후 재시도 여지 포함 |
| 토큰·비용 | U6 `get_budget_state()` 종속 배분 | U6 단일 권위 — U11 전용 CostGuard 없음 |

- **도구별 캡을 두는 이유**: 총량만 두면 한 도구가 예산을 독식한다(novelty 실측 — 검색 캡 소진으로 산출물 미완).
- **수치 변경은 문서 갱신을 동반한다**. 실측 없이 조정하지 않는다.
- U12가 D5 포트로 호출할 때는 **호출자 예산에 맞춰 축소 배분**한다.

---

## 4. 확장성

- **stateless 루프** — 상태는 세션·턴·트레이스 저장소에 있고 워커는 수평 복제 가능.
- 도구 실행은 I/O 대기가 지배적이라 **비동기 I/O + 제한된 병렬**을 허용한다(동일 도구의 무제한 팬아웃은 금지 — 캡이 상한).
- 백그라운드 색인은 요청 경로와 **분리된 실행 단위**여야 한다(응답 스레드를 점유하지 않는다).

---

## 5. 신뢰성 (NFR-R2)

| 의존성 | 장애 처리 | 결과 |
|---|---|---|
| LLM | 타임아웃 + 재시도 1회 + 서킷 브레이커 | `abstain(llm_unavailable)` |
| 검색 인덱스(U2) | 타임아웃 → 불가 신호 전달 | 근거 0이면 `abstain(out_of_corpus)`, 아니면 확인 범위 표기 후 성공 |
| DocModel 스토어 | 개별 논문 읽기 실패는 건너뜀 | 부분 실패 허용 |
| **외부 논문 소스** | 재시도 1회 + 서킷 브레이커 | 그 도구만 실패로 기록, 루프는 계속 |
| **인제스천 빌드 경로(승격)** | 실패·라이선스 차단은 정상 결과값 | `abstract` 범위로 수렴 — 예외로 루프를 깨지 않는다 |
| 자산 스토어(그림) | 부재와 장애를 **구분**해 안내 | 장애 시 "이미지 조회를 반복하지 말라"는 수리 지시 |
| 세션 저장소 | 타임아웃 + 재시도 | `TurnErrorResult` |
| 잡 큐 | best-effort enqueue | 실패 시 동기 경로 폴백 또는 에러 |

- **fail-closed**: LLM 장애·비용 저하는 기권 또는 에러로 수렴하고 내부 상세를 노출하지 않는다.
- **부수 경로 비차단**: 백그라운드 색인·텔레메트리·트레이스 발행 실패가 답변을 막지 않는다.
- **중단 안전성**: 루프가 중간에 죽어도 그때까지의 트레이스와 누적 근거는 일관되게 남아야 한다(잡 경로는 재개 대신 **부분 결과 + 확인 범위**로 마감).

---

## 6. 비용 (NFR-C1)

- **비용 특성 변화**: v1은 턴당 LLM 1회(추출). v2는 `decide` 반복 + `extract_evidence` 반복 + 승격 임베딩. **턴당 비용 분산이 v1보다 크다.**
- U6 예산 상태가 저하면 **루프 시작 전 기권**한다(호출 후 중단이 아니라 진입 차단).
- 승격 비용은 편수에 비례하므로 `fetch_paper` 캡이 실질적인 비용 상한 역할을 한다.
- 그림 조회는 이미지 토큰이 붙는다 — 캡 6회가 상한이며 첨부는 1회성이라 반복 계상되지 않는다.

---

## 7. 보안 (SEC-8/9/11/15)

- 인가·레이트리밋은 게이트웨이·U3 위임(중복 구현 금지).
- **프롬프트 신뢰 경계**: 도구 결과·논문 본문·그림 이미지는 시스템 지시와 분리된 구획에 넣는다.
- **외부 payload allowlist**: 어댑터가 기계식으로 강제(BR-EV-20).
- **트레이스 노출 경계**: 도구 인자 원문·자격증명·게이트 탈락 상세는 저장·노출 모두에서 sanitize.
- 승격 대상 URL은 서버가 외부 요청을 하는 지점이므로 **허용 호스트 목록**으로 제한한다(내부망 접근 방지).

---

## 8. 관측성 (NFR-O1)

- 1차 산출물은 **결정 트레이스**(FR-46) — 도구·질의 요약·결과 요약·상태·비용.
- 지표: 턴 지연, 루프 반복 수 분포, 도구별 호출·실패율, **게이트 탈락률**(날조 검사가 실제로 걸러내는 양), 승격 성공/차단/실패 비율, 기권 사유 분포.
- **게이트 탈락률은 회귀 신호다** — 급증은 프롬프트·투영 정합 붕괴를 뜻한다(v1의 캡션 표기 불일치가 그 예).

---

## 9. 테스트 (QT-8)

- PBT-EV-1~5 승계 + **PBT-EV-6(게이트 통과 불변)·7(루프 상한 불변)·8(범위 표기 불변)** 신설.
- 실입력 픽스처는 u1 회귀 픽스처(ar5iv HTML·GROBID TEI) 재사용 — 표·수식·그림 블록이 실제로 인용 가능한지 검증한다.
- 루프 테스트는 **도구 대역(fake)** 위에서 결정론적으로 돌린다(LLM 응답은 스크립트).
- 게이트 테스트는 로컬 스택(postgres·redis·S3 호환·OpenSearch)에서 **스킵 0**을 확인한다.
