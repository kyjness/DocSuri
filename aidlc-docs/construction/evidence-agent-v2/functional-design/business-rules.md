# Evidence Agent v2 (U11) — 비즈니스 규칙 (Business Rules)

**단계**: CONSTRUCTION → Functional Design (재설계 라운드) · **유닛**: U11 문헌탐색·근거형성 · **일자**: 2026-07-28
**원칙**: 결정 규칙·검증·제약(기술 무관). 수치 임계·구체 기술은 NFR/Infra.
**근거**: 요구사항 게이트 Q1~Q15 · FD 게이트 Q1~Q12 · `requirements.md` FR-36~38·FR-31·FR-45~47·FR-5·C-2·SEC-8/9 · v1 frozen `u11-evidence-agent/business-rules.md`.
**승계 방식**: v1의 INV-EV-1~5 · BR-EV-1~12를 **원칙적으로 승계**하고, 루프 구조에서 의미가 바뀐 것만 개정한다. 신규는 BR-EV-13~20.

---

## 1. 불변식 (INV-EV-*)

### INV-EV-1 — 세션 소유권 (승계, 무변경)
`ownerId`는 생성 후 변경 불가. 조회·턴 추가·삭제·초기화는 소유자 본인만. 타인 세션 접근은 **404**(존재 여부 비노출). 소유권 판정은 U3 단일 권위에 위임한다.

### INV-EV-2 — 빈 성공 금지 (승계, 무변경)
누적 근거가 0건이면 `TurnAbstainResult`. 근거 0건을 `state=ok`로 반환하는 것은 금지한다. **에이전트가 "충분하다"고 판단해도 누적이 0이면 정상 종료로 인정하지 않는다.**

### INV-EV-3 — 날조 금지·추출 경계 (**개정** — C-2, FR-47)
- `EvidenceItem.statement`는 확보한 출처 텍스트에서 추출한 명제만 허용한다. LLM이 생성한 새 산문·없는 수치·없는 주장의 삽입은 금지.
- `SourceRef.quote`는 **원문 스니펫만** 허용한다.
- **(v2 개정)** 검증 대상이 문장에서 **DocModel 전 블록 타입**으로 확장된다. 블록별 대조 텍스트는 `paragraph`·`code`=본문 / `list`=항목 / `table`=캡션+행 직렬화 / `formula`=LaTeX / `figure`=캡션.
- **(v2 신설)** 인용문은 **`anchor`가 가리키는 그 블록의 투영 안에** 있어야 한다. 문서 어딘가에 존재하는 것만으로는 부족하다.
- **(v2 신설)** `sourceScope=figure`(그림 해석) 근거의 숫자는 그 논문 텍스트에 실재해야 한다.
- 게이트는 **기계식**이다 — LLM-judge를 도입하지 않는다.

### INV-EV-4 — 첨부 원시 파일 미저장 (승계, 무변경)
첨부는 DocModel 추출 후 즉시 폐기한다. 원시 파일 영구 저장 금지(C-1 준용).

### INV-EV-5 — 내부 정보 비노출 (**개정** — SEC-9)
벡터 점수·청크 id·LLM 내부 상태·근거화 위반 상세는 사용자 응답에 노출 금지. `abstainReason`은 비기술 사유만.
**(v2 확장)** 결정 트레이스·활동 피드에도 같은 경계를 적용한다 — 도구명·질의 요약·건수·상태까지만 노출하고, 도구 인자 원문·게이트 탈락 상세·자격증명은 제외한다.

### INV-EV-6 — 근거 단일 유입 경로 (**신설**)
결과에 실리는 모든 `EvidenceItem`은 `extract_evidence`의 게이트를 통과한 것이어야 한다. 게이트를 우회해 누적기에 넣는 경로는 존재하지 않는다.

### INV-EV-7 — DocModel 단일 writer (**신설**)
U11은 DocModel을 쓰지 않는다. 온디맨드 승격은 U1의 빌드 경로에 **요청**하는 형태이며, U11이 자체 파서·저장 경로를 갖지 않는다.

## 2. 근거형성 규칙

### BR-EV-1 — 기권 조건 (**개정**)
다음이면 `TurnAbstainResult`: 관련 논문 없음(`out_of_corpus`), 게이트 통과 근거 0건(`insufficient_evidence`), LLM 장애(`llm_unavailable`), 비용 저하(`cost_degraded`). **날조 대신 기권** — fail-closed.
**(v2)** 예산 소진은 기권 사유가 **아니다** — 검증된 근거가 있으면 성공 + 확인 범위 표기(BR-EV-15).

### BR-EV-2 — 검색 scope 분기 (승계)
`auto`/`explicit`/`mixed`. `explicit`은 명시 집합만 사용하고 자동 검색을 금지한다. 생략 시 `auto`.
**(v2)** scope는 **탐색 대상 집합의 제약**으로 남고, 질의 문구 설계는 루프 판단이다. `explicit`에서도 루프는 그 집합 안에서만 검색·심화한다.

### BR-EV-3 — 멀티턴 맥락 (**개정**)
후속 턴은 같은 세션의 이전 턴 결과를 맥락으로 참조한다. **(v2)** 무엇을 이어받고 무엇을 새로 검색할지는 루프의 판단이며, 정규식 기반 의도 분류·질의 이어붙이기는 폐기한다.

### BR-EV-4 — 첨부 처리 (승계, 무변경)
형식·크기 검증은 루프 시작 **전**. 실패 시 즉시 에러. 유효 첨부는 공용 doc-model 경로로 처리해 근거 대상에 포함하고, 개별 첨부 실패는 건너뛰고 계속한다(부분 실패 허용).

### BR-EV-5 — 비교표·쟁점 조립 (승계, 무변경)
`claims`는 논문 간 비교형으로 구성한다(단순 나열 금지). 지지·상충을 함께 제시하며 상충이 없으면 빈 배열을 허용한다. **조립은 결정론** — LLM 호출 없음.

## 3. 루프 안전 규칙 (신설 — FR-45, FR-46)

### BR-EV-13 — 3중 한도
루프는 (반복 수, 도구별 호출 수, 토큰·비용) 세 한도 안에서만 동작한다. 초과 시 도구를 실행하지 않고 `budget_denied`를 기록한 뒤 종료 경로로 간다. 비용 판단은 U6 단일 권위이며 U11 전용 CostGuard를 만들지 않는다. **수치는 NFR에서 확정하고, 변경 시 문서 갱신을 동반한다.**

### BR-EV-14 — 승격 비용 계상
온디맨드 승격의 취득·파싱·임베딩 비용은 `LoopBudget`에 계상한다. 백그라운드 색인분도 계상 대상이다(비동기라고 무료가 아니다).

### BR-EV-15 — 확인 범위 표기
탐색이 완결되지 않은 채 종료했고 게이트 통과 근거가 1건 이상이면, **검증된 근거를 반환하고** `EvidenceCoverage`에 확인한 논문 수·후보 수·중단 사유를 싣는다. 터미널 상태는 `ok|abstain` 2종을 유지한다(새 상태를 만들지 않는다). 사용자 문구에는 내부 용어를 쓰지 않는다.

### BR-EV-16 — 트레이스 기록
모든 도구 실행은 `ToolCallRecord`로 기록한다(도구명·인자 요약·결과 요약·상태·비용·시각). 트레이스는 턴에 귀속되어 owner-scoped로 저장·삭제되며, **진행 활동 피드의 유일한 원천**이다.

### BR-EV-17 — 도구 결과의 신뢰 경계
도구 결과(검색 결과·논문 본문·그림 이미지·외부 응답)는 **신뢰 경계 밖 데이터**다. 시스템 지시 구획과 분리해 전달하고, 그 안의 문장을 지시로 해석하지 않는다. 이미지 첨부는 `decide` 직후 소비 후 폐기한다(1회성 — 재전송 방지).

### BR-EV-18 — 도구 오류의 수리 지시성
도구가 실패를 반환할 때는 **무엇이 틀렸는지와 다음에 무엇을 하면 되는지**를 함께 담는다. 사유 없는 실패는 루프가 같은 실수를 반복하게 만든다. 오류 문구도 무해화 파이프라인을 거친다.

## 4. 출처 등급 규칙 (신설 — FR-31, FR-47)

### BR-EV-19 — 근거 범위 표기
모든 `SourceRef`는 `sourceScope`를 갖는다.

| 범위 | 조건 | 검증 |
|---|---|---|
| `fulltext` | DocModel을 확보한 논문 | 블록 대조 + 앵커 실재성 + 숫자 부분집합 |
| `abstract` | 승격 실패·비OA로 초록만 확보 | 취득한 초록과 대조 + 숫자 부분집합. `anchor` 없음 |
| `figure` | 그림 해석 기반 | 숫자 실재성만(정성 서술은 표시로 갈음) |

- `sourceScope=fulltext`인 출처는 **반드시 DocModel 앵커를 갖는다**(PBT 대상).
- 외부 논문의 식별자는 **버전을 고정**한다(`arxiv:{id}v{n}`) — 사후 감사는 그 버전 재취득으로 재현한다. 초록 원문은 영속 저장하지 않는다.
- 코퍼스 밖 논문을 배제하지 않는다 — 승격 실패해도 초록 범위로 근거표에 남는다.

### BR-EV-20 — 외부 탐색 payload 경계
외부로 나가는 도구는 도구별 허용 payload(질의·키워드·논문 제목)를 어댑터가 **기계식으로 강제**한다. 사용자 원문·근거 전문·세션 내용을 외부에 보내지 않는다.

## 5. 스트리밍·비동기·비용 (승계)

### BR-EV-6 — 스트리밍 우선 / 비동기 잡 (승계)
기본은 SSE 스트리밍, 복잡 요청(승격 다수·첨부)은 비동기 잡 오프로드 + 폴링. **잡 경로도 동일 게이트·기권 규칙을 적용한다.** 진행 중 경로 전환은 하지 않는다.

### BR-EV-7 — 비용 게이트 (승계)
LLM 호출 직전 U6 `get_budget_state()` 확인. 저하 시 `cost_degraded`로 수렴하고 U11이 자체 비용 판단을 하지 않는다.

### BR-EV-8~10 — 세션 삭제·초기화·목록 (승계, 무변경)
소프트 삭제, 소유자 전체 초기화, `updatedAt` 내림차순 목록. 삭제 시 턴·결과·**트레이스**를 함께 파기한다(v2 추가 대상).

### BR-EV-11 — 레이트리밋 위임 (승계) · BR-EV-12 — fail-closed (승계)
게이트웨이가 강제하며 U11은 중복 구현하지 않는다. LLM 장애·타임아웃·비용 OPEN은 기권 또는 에러로 수렴하고 내부 상세를 노출하지 않는다.
