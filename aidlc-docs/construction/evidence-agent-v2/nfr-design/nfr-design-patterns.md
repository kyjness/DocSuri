# Evidence Agent v2 (U11) — NFR 설계 패턴 (NFR Design Patterns)

**단계**: CONSTRUCTION → NFR Design (재설계 라운드) · **유닛**: U11 · **일자**: 2026-07-28
**근거**: `nfr-requirements.md` · `functional-design/*` · `backend/CLAUDE.md` 에이전트 루프 체크리스트 · novelty v2 운영 교훈(⑤1~⑤3).

---

## 1. 게이트 fail-closed — 단일 유입 경로

근거가 결과에 들어가는 경로는 `extract_evidence` **하나**이고, 그 안에서만 게이트가 돈다(INV-EV-6). 우회 경로를 만들지 않는 것이 이 패턴의 전부다.

- 게이트는 **순수 함수**로 둔다(입력: 후보 항목 + 출처 텍스트 + DocModel / 출력: 통과분 + 탈락 사유). LLM·네트워크를 타지 않아 PBT 대상이 된다.
- 탈락은 예외가 아니라 **정상 결과값**이다. 예외로 만들면 루프가 깨지고, 조용히 통과시키면 C-2가 깨진다.
- 탈락 사유는 **집계만** 사용자·트레이스에 노출하고 상세(어떤 quote가 왜)는 내부에 둔다(INV-EV-5).

## 2. 자율 루프의 폭주 방지

| 장치 | 형태 |
|---|---|
| 3중 한도 | 반복·도구별 호출·토큰. **검사는 도구 실행 전** — 실행 후 차감은 초과를 이미 지출한 뒤다 |
| 초과 처리 | 도구를 실행하지 않고 `budget_denied` 기록 → 종료 경로. 예외를 던지지 않는다 |
| 진입 차단 | U6 예산이 저하면 **루프 시작 전** 기권 |
| 종료 판정 권위 | 에이전트가 "충분"이라 해도 누적 근거 0이면 정상 종료 아님(INV-EV-2) |

## 3. 관찰 설계 — 반복 호출을 끊는 두 가지

novelty ⑤3의 실측 교훈을 그대로 승계한다.

- **결과 줄에 호출 인자를 함께 싣는다**. 결과만 보이면 모델은 그것이 어떤 호출에서 나왔는지 몰라 같은 질의를 반복하고, 반복이 캡을 태워 근거를 못 채운 채 종료한다.
- **이미지 첨부는 `decide` 직후 소비하고 폐기한다**. 관찰 윈도우에 남기면 밀려날 때까지 매 턴 재전송되어 같은 토큰이 반복 계상된다. 도구 실행 뒤에 소비 지점을 두면 종료 제안이 거부돼 도구 없이 되도는 경로에서 재전송이 남는다.

## 4. 신뢰 경계 (prompt injection)

- 도구 결과·논문 본문·그림 이미지·외부 응답은 **시스템 지시와 다른 구획**에 넣는다. 이미지는 도구 결과 구획 **뒤에** 배치하고, 그림 안의 문장이 지시가 아님을 시스템 프롬프트가 명시한다.
- 모델이 쓴 값(질의·`recordRef`·`asset_id`)이 그대로 어댑터에 들어가므로 **경계에서 검증**한다 — 길이 상한, 형식 파서, 허용 호스트 목록. 스펙의 `maxLength`는 모델에 대한 안내일 뿐 강제가 아니다.
- 오류 문구도 모델 입력으로 되돌아가므로 **같은 무해화 파이프라인**을 거친다.

## 5. 의존성별 격리

실패 도메인마다 서킷 브레이커를 하나씩 둔다(공유 `CircuitBreaker` 구현 재사용): LLM · 검색 인덱스 · DocModel 스토어 · 외부 논문 소스 · 자산 스토어 · 인제스천 빌드.

- **부재와 장애를 구분한다.** 자산 1건 없음은 "다른 자산을 고르라", 스토어 장애는 "이미지 조회를 반복하지 말고 텍스트로 진행하라" — 뭉개면 로드될 수 없는 자산으로 캡을 전부 태운다(⑤3 실측).
- 승격 실패(라이선스·파싱)는 **장애가 아니라 정상 결과값**이므로 브레이커 실패로 집계하지 않는다.

## 6. 저하 계층

| 계층 | 발동 | 표면 |
|---|---|---|
| 진입 차단 | U6 예산 저하 | `abstain(cost_degraded)` |
| 부분 성공 | 예산 소진·부분 실패 + 근거 1건 이상 | `ok` + **확인 범위 표기** |
| 범위 저하 | 승격 실패·비OA | 그 출처만 `sourceScope=abstract` |
| 기권 | 근거 0건 | `abstain(insufficient_evidence` / `out_of_corpus)` |
| 오류 | 복구 불가 | `TurnErrorResult` (내부 상세 비노출) |

**터미널 상태는 2종을 유지**하고 저하는 필드로 표현한다 — D5 union을 늘리면 U12·FE 분기가 함께 늘어난다.

## 7. 부수 경로 비차단

백그라운드 색인·텔레메트리·트레이스 발행 실패는 **답변을 막지 않는다**. 이 저장소의 기존 규칙과 같다(자산 추출·이벤트 발행이 이미 그렇게 동작한다).

- 다만 **삼키는 것과 안 보이는 것은 다르다** — 실패는 반드시 경고 로그 + 지표로 남긴다. u7의 "모든 예외를 삼켜 `None`을 반환해 캐시 미스와 구분되지 않던" 사례가 반례다.

## 8. 중단 안전성

- 트레이스는 **append-only**로 쓴다. 턴 행을 계속 갱신하면 스트리밍 중 결과 쓰기와 경합한다.
- 잡 경로의 결과 확정은 **조건부 갱신(원자적)** — 큐의 at-least-once 재배달로 두 워커가 같은 잡을 처리해도 먼저 확정된 결과가 덮이지 않는다(v1 선례 승계).
- 루프가 중간에 죽으면 재개하지 않고 **부분 결과 + 확인 범위**로 마감한다. 재개는 도구 부작용(승격·색인)의 멱등성을 전제로 하는데, 그 전제를 v1 범위에서 세우지 않는다.

## 9. 관측 지표

턴 지연 · 루프 반복 수 분포 · 도구별 호출·실패율 · **게이트 탈락률** · 승격 성공/차단/실패 비율 · 기권 사유 분포 · 토큰·비용.

- **게이트 탈락률이 회귀 신호다.** 급증은 프롬프트 표현과 대조 투영이 어긋났다는 뜻이다(v1의 캡션 콜론 불일치가 정확히 그 형태였고, 지표가 없어 드러나지 않았다).

## 10. 결정론 유지

조립(비교표·쟁점)과 게이트는 LLM을 타지 않는다. 같은 입력이면 같은 출력이어야 하고, 그래야 PBT와 회귀 픽스처가 성립한다. **LLM-judge를 도입하지 않는다**는 것이 U7 grounding 게이트와 공유하는 원칙이다.
