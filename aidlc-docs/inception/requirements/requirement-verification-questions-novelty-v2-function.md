이 에이전트는 사용자에게 무엇을 해주는 존재인가?

- **A) 연구 아이디어 파트너** — 연구 주제(또는 원고)를 주면, 관련 연구를 조사하고 그 근거 위에서 차별화된 연구 방향과 실험 계획을 제안한다. *(현행 임무와 동일)*

## Q4 — 상호작용 방식

사용자와 에이전트는 어떻게 만나는가?

- **A) 잡 실행형** *(현행)* — 입력 → 실행 → 진행 표시 → 결과. 실행 중 개입 없음.
- **B) 잡 + 대화 스티어링** — 기본은 잡 실행형인데, 실행 중·완료 후 채팅으로 방향 수정과 후속 지시가 가능. *세션 메모리(잡 내 멀티턴)와 자연스럽게 연결.*
